# Sharma Event Management

Static Vite + React site for Sharma Events (Haldwani / Kathgodam / Nainital / Uttarakhand).

No backend — content lives in `src/data/`. Contact form opens WhatsApp.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Upload the contents of `dist/` to Hostinger `public_html`.

See [DEPLOY-HOSTINGER.md](./DEPLOY-HOSTINGER.md).

## Edit content

Update modules under `src/data/`, then rebuild.
